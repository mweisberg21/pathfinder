Privacy.

The Mac app

Pathfinder 0.1.0 has no account, analytics, advertising, or network requests. It does not upload your files or store your chat text.

Search and saved locations

Filename search uses the Spotlight index on your Mac. Direct directory browsing and the file chooser use macOS file access. Pathfinder does not build an index of your file contents.

Pinned paths, preferences, and frequently used locations are saved locally. You can disable usage history, clear it, and remove pins in Settings. Spotlight exclusions and macOS file permissions still apply.

Inserting a path

Optional Accessibility permission lets Pathfinder locate the original text field and paste the path you choose. It uses app and field identity, selection, and position information to return to that field; it does not read or retain the contents of your conversation.

The selected path stays on your clipboard. Pathfinder does not maintain clipboard history, paste into secure fields, or submit your message. You can use Search and Copy without enabling insertion. A path is plain text, not a file upload or a grant of access to the file.

This website and downloads

This site has no analytics scripts, advertising, account system, or tracking cookies added by Pathfinder. The interactive demo uses fictional sample paths and does not access your filesystem, clipboard, or chat apps.

GitHub hosts this website and its release downloads. Requests to GitHub are subject to GitHub’s privacy statement. This is separate from the local Mac app.

Questions

Open an issue on GitHub. Issues are public; avoid including private file paths or conversation content.
