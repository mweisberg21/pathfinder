Release notes.

0.1.0 · Early release

October 13, 2026 · Apple silicon · macOS 14+

  • Customizable global shortcut. Control–Option–Space by default.
  • Spotlight filename search, file and folder filters, pins, and frequently used paths.
  • Insert a path into the original text field, or copy without Accessibility permission.
  • Full, home-relative, shell-quoted, and file URL path formats.
  • Local preferences and history. No account, analytics, or file uploads.

Verification

The app and installer are signed with Developer ID, notarized by Apple, and stapled. Gatekeeper accepts both on the build Mac. All 17 Release-mode tests passed, and path insertion was tested with ChatGPT and Claude.

This is an early release. A fresh installation on another Mac remains unverified. This build does not support Intel Macs.

A path is plain text, not a file attachment or permission for another app to read it. Spotlight exclusions and macOS file permissions still apply.
